# Plan review

Review the draft against the original request and confirmed decisions. Read relevant
repository guidance, code, and tests. Check implementation feasibility, integration,
correctness, scope, unnecessary complexity, and whether the acceptance checks prove success.

Report only material, evidenced gaps with severity, supporting file references, and the
smallest plan correction. Respect the user's decisions and do not expand scope or edit
files. State whether the plan is ready and identify any unresolved blockers.
